### 4. A Typical Engineering Workflow

1. Someone reports a bug.
2. Investigate the issue.
3. Find three more bugs along the way.
4. Fix the original issue.
5. Review someone else's PR.
6. Find another 15 things to improve.
7. Deploy.
8. Wonder what broke this time.
